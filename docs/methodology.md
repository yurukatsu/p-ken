## 1. 記法

| 記号 | 意味 |
|---|---|
| $i$ | 銘柄 |
| $t$ | 営業日（リターンの日） |
| $k$ | ファクター |
| $m(t)$ | $t$ の **前月末**（例：$t$ = 2026/08/03 なら $m(t)$ = 2026/07 末） |
| $U_m$ | 月末 $m$ のユニバース構成銘柄（`data/<universe>/universe/{m}.csv`） |
| $r_{i,t}$ | 銘柄 $i$ の日 $t$ のリターン（小数）。デフォルトは **現地通貨建てトータルリターン**（`ret`）。スペシフィックリターン（`sret`）にも差し替えられる |
| $x_{i,k}$ | 銘柄 $i$ のファクター $k$ へのエクスポージャー（生の値） |
| $z_{i,k,t}$ | 日 $t$ の推定に使う標準化後のエクスポージャー |
| $f_{k,t}$ | ファクター $k$ の日 $t$ のファクターリターン |

ユニバースは 2 つです。

| キー | ユニバース | データ |
|---|---|---|
| `gemq` | MSCI EM | `data/gemq` |
| `blf` | RGA | `data/blf` |

## 2. 時点のそろえ方

### リターン

`rtn/{m}.csv` には、**月末 $m$ のユニバース $U_m$ の銘柄について、翌月の日次リターン** が入っています。
つまり日 $t$ のリターンは `rtn/{m(t)}.csv` から読み、そのときのユニバースは前月末の $U_{m(t)}$ です。
期中に除外された銘柄も、その月の終わりまでリターンが入っています（生存バイアスなし）。

（コード：`p_ken.factors.engine.iter_days`）

### エクスポージャー（形成時点）

日 $t$ のリターンに使うエクスポージャーは、$t$ より前に分かっている値です。

| 種類 | 形成時点 $\tau(t)$ | 使う場面 |
|---|---|---|
| 月次 | 前月末 $m(t)$ | core ファクター、MSCI EM の NAM（AI / Revision / GEMQ3） |
| 日次 | $t$ より **厳密に前** で最新のスコアファイルの日 | RGA の NAM（AI / TVL / RVL / ai70_bd30） |
| 月末（互換） | $t$ 以前で最新の月末営業日（月末日当日はその日のスコア） | RGA の Q5 版（archive の em-market-weekly と同じ。§12） |

（コード：`p_ken.factors.sources`）

## 3. 推定に使う銘柄

日 $t$、ファクター $k$ の推定に使う銘柄の集合を

$$
S_{k,t} = \{\, i \in U_{m(t)} \;:\; r_{i,t}\ \text{が観測},\ |r_{i,t}| < 100\%,\ x_{i,k}\ \text{が観測},\ x_{i,k} > -100 \,\}
$$

とし、$n_{k,t} = |S_{k,t}|$ とします。

- $x \le -100$ はデータ上の欠損コード（例：−999999998）なので欠損とみなします。
- 欠損したエクスポージャーは、そのファクターの推定からだけ除きます（他のファクターには影響しません）。
- サブユニバース（例：中国だけ）で計算する場合は、$U_{m}$ をその銘柄に絞ります（`stocks=` 引数）。

## 4. エクスポージャーの標準化（Blom スコア）

$S_{k,t}$ の中で $x_{i,k}$ に順位 $R_{i}$（同順位は平均順位、1 が最小）をつけ、

$$
z_{i,k,t} = \Phi^{-1}\!\left( \frac{R_i - 3/8}{\,n_{k,t} + 1/4\,} \right)
$$

とします（$\Phi^{-1}$ は標準正規分布の分位関数）。

- 順位だけで決まるので、外れ値や単調変換（対数をとる等）の影響を受けません。
- 平均はほぼ 0、分散はほぼ 1 になります。ファクター間・日の間で $f$ の大きさを比べられます。
- 毎日、その日の $S_{k,t}$ で計算し直します（銘柄の出入りに対応）。

`standardize="zscore"`（$(x-\bar x)/s_x$）や `"raw"`（そのまま）にも切り替えられます。

（コード：`p_ken.stats.blom`、`p_ken.factors.engine.STANDARDIZE`）

## 5. ファクターリターン：単回帰（デフォルト）

ファクターごとに、日 $t$ の横断面で 1 変数の回帰

$$
r_{i,t} = a_{k,t} + f_{k,t}\, z_{i,k,t} + \varepsilon_{i,k,t}, \qquad i \in S_{k,t}
$$

を最小二乗法で推定し、傾き $f_{k,t}$ をファクターリターンとします。

$$
\hat f_{k,t} = \frac{\sum_{i \in S_{k,t}} (z_{i,k,t} - \bar z_{k,t})(r_{i,t} - \bar r_{k,t})}{\sum_{i \in S_{k,t}} (z_{i,k,t} - \bar z_{k,t})^2}
$$

（$\bar z_{k,t}, \bar r_{k,t}$ は $S_{k,t}$ での平均。$n_{k,t} < 3$ またはばらつきがない場合は欠損）

### 解釈

$\hat f_{k,t}$ はポートフォリオのリターンとして書けます。

$$
\hat f_{k,t} = \sum_{i} w_{i}\, r_{i,t}, \qquad
w_{i} = \frac{z_{i} - \bar z}{\sum_j (z_j - \bar z)^2}
$$

このウェイトは

$$
\sum_i w_i = 0 \quad(\text{ロング・ショートでコストゼロ}), \qquad
\sum_i w_i\, z_i = 1 \quad(\text{エクスポージャーがちょうど } 1)
$$

を満たします。つまり **「エクスポージャーが 1（≒ 1σ）高いことで、1 日にどれだけリターンが上乗せされたか」** です。

- $\sum_i w_i = 0$ なので、全銘柄に共通の動き（市場全体の上げ下げ）は切片 $a_{k,t}$ に吸収され、$\hat f$ に影響しません。リターンからユニバース平均を引いた超過リターンで回帰しても同じ値になります。
- 1 ファクターずつの回帰（単回帰）なので、相関の高いファクター同士の影響は分離していません（例：Value と Momentum）。

（コード：`p_ken.stats.slopes`、`p_ken.factors.engine.regression_returns`）

### 通貨

デフォルトの $r_{i,t}$ は現地通貨建てです。USD 建てリターンは近似的に「現地通貨建てリターン＋その国の為替変動」で、為替の部分は同じ国の銘柄に共通です。エクスポージャーが国ごとに偏っているファクターでは、USD 建てにすると為替の動きが $\hat f$ に混ざります。現地通貨建てはそれを除いた、銘柄選択としての効きを見る定義です。

## 6. ファクターリターン：分位ポートフォリオ（Q5 版）

比較用に、上位分位ポートフォリオの超過リターンも計算できます（`method="q5"`）。

1. エクスポージャーで銘柄を $q$ 分位（デフォルト 5）に分けます。分位の境界の決め方は 2 通りです。
   - **formation**：形成時点ごと、ユニバース内で `dplyr::ntile` と同じ方法で等分（R の `fret_nam_monitor`）
   - **pooled**：期間中の「日 × 銘柄」をまとめて `pd.qcut`（archive の `BLF.fret_nam_daily`、em-market-weekly）
2. 超過リターン $e_{i,t} = r_{i,t} - \frac{1}{|U_t|}\sum_{j} r_{j,t}$（その日の単純平均との差）
3. 最上位分位 $Q_{q}$ の平均

$$
f^{Q}_{k,t} = \frac{1}{|Q_{q,k,t}|} \sum_{i \in Q_{q,k,t}} e_{i,t}
$$

`group="spread"` で $Q_q$ と $Q_1$ の差（ロング・ショート）にもなります。

回帰版との違い：回帰版は全銘柄を Blom スコアで重み付けした「1σ あたり」の値、Q5 版は上位 20% だけの「平均との差」です。Q5 版の方が数字は大きく出ます。

（コード：`p_ken.factors.engine.quantile_returns`）

## 7. 累和と期間合計

図には、年初来の開始日 $t_0$（`ytd_start`）からの **累和** を描きます。

$$
F_k(T) = \sum_{t_0 \le t \le T} f_{k,t}, \qquad F_k(t_0 - 1) = 0
$$

ファクターリターンは毎日組み替えるロング・ショートの 1 日あたりの値なので、複利ではなく単純に足し合わせます。
図の右端の数値は強調期間（四半期）の合計 $\sum_{t \in [t_s, t_e]} f_{k,t}$ です。

## 8. ファクタータイプ別の平均

core ファクターは `exposures/fc_list.csv` のタイプ $g$（Stock Value、Flow Value、Profitability など）ごとに等ウェイトで平均します。

$$
f_{g,t} = \frac{1}{|K_g|} \sum_{k \in K_g} f_{k,t}
$$

- 平均の前にファクターの向き（「高いほど良い」か「低いほど良い」か）はそろえていません。負債比率のように向きが逆のファクターが同じタイプに入っていると打ち消し合います。
- Seasonality は core ファイルにないので対象外です。RGA の fc_list には ILLIQ（Other）と WK_TA がありません。

（コード：`p_ken.factors.presets.type_returns`）

## 9. レポートで使う設定（プリセット）

| | ユニバース | ファクター | 形成時点 | 欠損・標準化 | 推定 |
|---|---|---|---|---|---|
| コモンファクター | MSCI EM、RGA | `exposures/core` の fc_list 掲載分（約 100） | 前月末 | まずユニバース内で Blom、欠損は 0 で埋める（`exp_em`）。その後、日ごとに Blom をとり直す | 単回帰 → タイプ平均 |
| NAM（MSCI EM） | MSCI EM | AI、Revision、GEMQ3 | 前月末 | 欠損は除外、日ごとに Blom | 単回帰 |
| NAM（RGA） | RGA | AI、TVL、RVL、ai70_bd30 | 前日まで最新のスコアファイル | 欠損は除外、日ごとに Blom | 単回帰 |
| NAM Q5（MSCI EM） | MSCI EM | 同上 | 前月末 | ユニバース内で ntile | Q5 の超過リターン |
| NAM Q5（RGA） | RGA | 同上 | 月末（互換） | 期間全体で qcut | Q5 の超過リターン |

すべて $r_{i,t}$ は `ret`（現地通貨建て）がデフォルトで、`sret` 版も出力します。

（コード：`p_ken.factors.presets`）

## 10. GEMQ3 スコア

R の `get_gemq3()` を移植したものです（MSCI EM、月末 $m$）。ここでの $\mathrm{Blom}_R$ は R の `calc_blom_score`（分母に最大順位を使う版。最大値に同順位がなければ §4 と同じ）です。

1. $\mathrm{airev}_i = \mathrm{Blom}_R\big((\mathrm{ai}_i + \mathrm{rev}_i)/2\big)$（欠損は 0）
2. $\mu = $ 中国（QIP の `ctry == "CN"`）銘柄の $\mathrm{airev}$ の平均
3. $\mathrm{qip}_i = \mathrm{Blom}_R(\text{invention\_count\_12m}_i) - \overline{\mathrm{Blom}_R} + \mu$（中国銘柄のみ、`rescale_mean`）
4. $$
   \mathrm{GEMQ3}_i = \mathrm{Blom}_R\!\left(\begin{cases}(\mathrm{ai}_i + \mathrm{rev}_i + \mathrm{qip}_i)/2 & \text{中国銘柄}\\ (\mathrm{ai}_i + \mathrm{rev}_i)/2 & \text{それ以外}\end{cases}\right)
   $$
5. ユニバースに結合し、欠損は 0

R の `rescale_mean` は平均に `na.rm` がなく、欠損が 1 つでもあると QIP 全体が 0 になります。ここでは欠損を除いて平均します（`--qip-na-strict` で R と同じ挙動）。

（コード：`p_ken.gemq3`）

## 11. 指数・国別・銘柄のリターン

**期間リターン**：開始日 $t_s$ の前の最後の終値から、終了日 $t_e$ 以前の最後の終値まで。

$$
R = \frac{P_{t_e}}{P_{t_s^-}} - 1, \qquad t_s^- = \max\{t < t_s\}
$$

- **指数の推移**（MSCI World / EM / RGA）：$100 \times P_t / P_b$、$b$ は `ytd_start` 以前の最後の日。MSCI はネット・トータルリターン（`--variant gross` でグロス、`close` で価格指数）。RGA は `rga.csv`（グロス・トータルリターン）。
- **国別・セクター別**：LSEG の USD 建て終値（`TR.PriceClose(Curn=USD)`、現地指数をその日の為替で換算）。マーカーは月末までの累積リターン（同じ基準）。
- **ツリーマップ**：セルの面積 = 期末のウェイト $w_i$、色 = 銘柄の USD 建て期間リターン $R_i$。グループの見出しは
  $\sum_{i \in G} w_i R_i \big/ \sum_{i \in G} w_i$。
  期末のウェイトなので、期中に上がった銘柄ほど重くなり、指数のリターンとは一致しません。

（コード：`p_ken.stats.period_return`、`p_ken.markets`）

## 12. em-market-weekly との違い

| | em-market-weekly | p-ken（デフォルト） |
|---|---|---|
| Common の推定 | 単回帰（同じ） | 単回帰 |
| Common のリターン | USD 建て価格リターン | 現地通貨建てトータルリターン |
| Common のユニバース | AI スコアファイルの銘柄（約 850） | ユニバースファイルの銘柄（RGA 約 590） |
| NAM の推定 | Q5 の超過リターン | 単回帰（Q5 版も出力） |
| NAM の分位 | 期間全体で qcut、既定は地域別 | 全体で qcut（地域対応表がサーバーにのみあるため） |
| NAM のタイミング | 月末スコアを翌月末まで | 前日までのスコア（Q5 版は em-market-weekly と同じ） |
| TVL | DB の factor_glb（factor_id 400） | bigdata ファイルの `tvl` |
